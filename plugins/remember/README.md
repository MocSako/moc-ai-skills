# remember

Continuous memory for Claude Code.

**Source:** [claude.com/plugins/remember](https://claude.com/plugins/remember)  
**By:** Digital-Process-Tools

## Install

```
/plugin remember
/reload-plugins
```

## What it does

- Saves your session automatically as you work
- Compresses history into daily summaries
- Loads that context back when you start a new session
- Run `/remember:doctor` to check if it's set up correctly

## Why I use it

One thing that got annoying fast was having to re-explain everything at the start of every session. Like I'd spend 10 minutes catching Claude up on what I was working on, what we already tried, what broke, what the plan was. Then the next day, same thing. It got old.

This plugin fixes that. It saves what happened during the session and loads it back automatically next time. Not perfect recall but enough that I don't have to start from zero every time I open Claude Code.

If you work across multiple sessions or projects this is worth having.
